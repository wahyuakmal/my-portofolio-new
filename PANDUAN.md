## 📂 2. Cara Membuka Project di Komputer

1. **Ekstrak File ZIP**:
   Ekstrak file ZIP source code ini ke folder di komputer kamu (contohnya di folder `Documents` atau `Desktop`).
2. **Buka Aplikasi VS Code**:
   Buka aplikasi **Visual Studio Code** yang sudah di-install.
3. **Buka Folder Projek**:
   - Klik menu **File** di pojok kiri atas ➔ pilih **Open Folder...**
   - Pilih folder hasil ekstrak tadi, lalu klik **Select Folder**.

## ⚡ 3. Menjalankan Website di Komputer (Localhost)

1. **Buka Terminal di VS Code**:
   - Klik menu **Terminal** di bagian atas ➔ pilih **New Terminal** (atau tekan `Ctrl + ~`).
2. **Install Bahan-Bahan Website** *(Hanya 1x di awal)*:
   Ketik perintah berikut di terminal lalu tekan **Enter**:
   ```bash
   npm install
   ```
   *Tunggu sekitar 1–3 menit sampai prosesnya selesai.*

3. **Jalankan Website**:
   Ketik perintah ini lalu tekan **Enter**:
   ```bash
   npm run dev
   ```
4. **Buka Website**:
   Akan muncul link seperti `http://localhost:5173`.  
   Tahan tombol **Ctrl** lalu **Klik link tersebut**, atau buka browser (Chrome/Edge) dan ketik `http://localhost:5173`.  
   🎉 **Selamat! Websitemu sudah jalan di komputermu sendiri!**

## 🗄️ 4. Cara Setup Database Supabase Sendiri (Lengkap Kode SQL)

Jika kamu ingin membuat database Supabase milikmu sendiri dari awal, ikuti langkah berikut:

### Langkah A: Buat Akun & Project Supabase
1. Buka situs **[Supabase.com](https://supabase.com/)** dan daftar/login menggunakan akun GitHub atau Email kamu (Gratis).
2. Klik tombol **New Project**.
3. Isi **Name** (contoh: *My Portfolio*), isi **Database Password** (catat password ini!), pilih Region terdekat (misal: *Singapore*), lalu klik **Create New Project**.

---

### Langkah B: Jalankan Kode SQL Otomatis (Tabel Database)
1. Di Dashboard Supabase kamu, klik ikon **SQL Editor** (ikon berbentuk `<>` di menu kiri).
2. Klik **New Query** di pojok atas.
3. **Copy & Paste seluruh kode SQL di bawah ini** ke dalam kolom SQL Editor:

```sql
-- 1. Buat Tabel Projects
CREATE TABLE IF NOT EXISTS public.projects (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  title TEXT NOT NULL,
  description TEXT,
  img TEXT,
  tech_stack TEXT[],
  features TEXT[],
  link TEXT,
  github TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. Buat Tabel Certificates
CREATE TABLE IF NOT EXISTS public.certificates (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  img TEXT NOT NULL,
  category TEXT DEFAULT 'keahlian',
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 3. Buat Tabel Experiences
CREATE TABLE IF NOT EXISTS public.experiences (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  company TEXT NOT NULL,
  role TEXT NOT NULL,
  year TEXT NOT NULL,
  logo TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 4. Buat Tabel Portfolio Comments
CREATE TABLE IF NOT EXISTS public.portfolio_comments (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  user_name TEXT DEFAULT 'Anonymous',
  content TEXT NOT NULL,
  profile_image TEXT,
  is_pinned BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- MATIKAN RLS / AKTIFKAN AKSES PUBLIK (AGAR BISA DI-CRUD DENGAN MUDAH)
ALTER TABLE public.projects DISABLE ROW LEVEL SECURITY;
ALTER TABLE public.certificates DISABLE ROW LEVEL SECURITY;
ALTER TABLE public.experiences DISABLE ROW LEVEL SECURITY;
ALTER TABLE public.portfolio_comments DISABLE ROW LEVEL SECURITY;
```

4. Klik tombol **Run** (tombol hijau di pojok kanan bawah).  
   ✅ *Jika muncul pesan "Success", semua tabel database kamu sudah otomatis dibuat!*

---

### Langkah C: Buat Storage Bucket (Tempat Upload Foto)
Website ini membutuhkan tempat menyimpan gambar project & sertifikat:
1. Di Dashboard Supabase, klik menu **Storage** (ikon folder di menu kiri).
2. Klik **New Bucket**.
3. Isi Bucket Name: **`project-images`** ➔ Pastikan centang **Public Bucket** diaktifkan (`ON`) ➔ Klik **Save**.
4. Buat 1 bucket lagi: Klik **New Bucket**, isi Bucket Name: **`certificate-images`** ➔ Pastikan centang **Public Bucket** diaktifkan (`ON`) ➔ Klik **Save**.

## 🔑 5. Menyiapkan File Kunci `.env`

File `.env` berfungsi sebagai "kunci rahasia" untuk menghubungkan website dengan Supabase.

1. Buka VS Code.
2. Klik kanan di area kosong panel file sebelah kiri ➔ pilih **New File**.
3. Beri nama file: **`.env`** *(Pakai titik di depannya!)*.
4. Di Supabase Dashboard kamu, masuk ke menu **Project Settings** (ikon roda gigi) ➔ **API**.
5. Copy **Project URL** dan **anon / public Key**, lalu masukkan ke file `.env` seperti ini:

```env
VITE_SUPABASE_URL=https://nama-project-kamu.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOi...kunci-anon-kamu-disini...
```

6. Tekan tombol **Ctrl + S** untuk menyimpan.

## 🔐 7. Cara Membuat Akun Admin & Menggunakan Dashboard

Website ini dilengkapi dengan **Dashboard Admin** rahasia untuk mengelola isi project, sertifikat, & foto galeri secara langsung tanpa perlu menyentuh kode!

### A. Cara Membuat Akun Admin Pertama Kamu:
1. Masuk ke Dashboard Supabase kamu ➔ pilih menu **Authentication** (ikon gembok/user di kiri).
2. Klik tab **Users** ➔ klik tombol **Add User** ➔ pilih **Create User**.
3. Masukkan **Email Admin** (misal: `admin@gmail.com`) dan **Password Admin** kamu ➔ klik **Create User**.

### B. Cara Masuk ke Dashboard Admin Website:
1. Buka browser dan jalankan websitemu, lalu masuk ke URL: `http://localhost:5173/login`
2. Masukkan Email & Password Admin yang sudah kamu buat di Supabase tadi.
3. Kamu akan masuk ke **Admin Panel Dashboard**!
   - **Projects**: Tambah/edit/hapus karya project.
   - **Certificates**: Kelola sertifikat keahlian & prestasi.
   - **Comments**: Pin atau hapus komentar pengunjung.

## 🌐 8. Cara Meng-online-kan Website Gratis (Deploy ke Vercel)

Ingin websitemu bisa dibuka oleh siapa saja di internet secara gratis? Pakai **Vercel**!

1. Buat akun gratis di **[Vercel.com](https://vercel.com/)** (login pakai akun GitHub kamu).
2. Upload projek ini ke repository **GitHub** milikmu.
3. Di Vercel Dashboard, klik **Add New ➔ Project**.
4. Pilih repository GitHub portofoliomu, lalu klik **Import**.
5. Di bagian **Environment Variables**, masukkan 2 kunci dari file `.env`:
   - `VITE_SUPABASE_URL` = *(URL Supabase kamu)*
   - `VITE_SUPABASE_ANON_KEY` = *(Anon Key Supabase kamu)*
6. Klik **Deploy**!
7. Dalam 1 menit, websitemu sudah **ONLINE di seluruh dunia** dengan domain gratis `.vercel.app`!

## ❓ 9. Solusi Masalah Sering Terjadi (Troubleshooting)

| Masalah / Error | Apa Penyebabnya? | Solusinya Bagaimana? |
| :--- | :--- | :--- |
| **`npm error` / `command not found`** | Node.js belum ter-install atau perlu di-restart | Install/re-install Node.js dari nodejs.org, lalu **restart laptop** kamu. |
| **Tampilan Web Kosong / Data Hilang** | File `.env` belum dibuat | Pastikan kamu sudah membuat file `.env` di folder utama sesuai [Langkah 5](#-5-menyiapkan-file-kunci-env). |
| **Gagal Upload Gambar di Dashboard** | Bucket Storage Supabase belum dibuat / belum Public | Buka Supabase ➔ Storage ➔ Pastikan bucket `project-images` & `certificate-images` diset ke **Public**. |
| **Port 5173 is in use** | Ada server lain yang masih berjalan | Tutup terminal VS Code, lalu jalankan `npm run dev` kembali. |
